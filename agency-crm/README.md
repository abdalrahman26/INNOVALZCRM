# Agency CRM

سيستم CRM لمبيعات الإيجنسي — Next.js + Supabase، جاهز للرفع على Vercel.

---

## التشغيل في 5 خطوات

### 1) Supabase
1. اعمل مشروع جديد على [supabase.com](https://supabase.com).
2. افتح **SQL Editor ← New query**، الصق محتوى `supabase/schema.sql` كله، ودوس **Run**.
   - لو ظهر خطأ عند `pg_cron`: فعّله من **Database ← Extensions ← pg_cron** وشغّل الملف تاني.
3. **Authentication ← Users ← Add user**: اعمل حسابك (إيميل + باسورد، وعلّم Auto Confirm).
   **أول حساب بيبقى أدمن تلقائياً.**
4. **Authentication ← Sign In / Providers ← Email**: اقفل **Allow new users to sign up** (الحسابات بتتعمل من جوه السيستم بس).
5. من **Project Settings ← API** خد: `Project URL` و`anon key` و`service_role key`.

### 2) Vercel
1. ارفع الفولدر على GitHub (repo جديد).
2. في Vercel: **Add New ← Project** واختار الـ repo.
3. في **Environment Variables** ضيف:

| الاسم | القيمة |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon key |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role key (سري) |
| `NEXT_PUBLIC_APP_NAME` | اسم الإيجنسي |
| `WEBHOOK_SECRET` | أي كلمة سر طويلة |

4. **Deploy** ✅

### 3) أول استخدام
1. ادخل بحسابك ← **الفريق والصلاحيات** ← ضيف السيلز.
2. **استيراد شيت** ← ارفع الليدز.
3. **التوزيع التلقائي** ← حدد كل كام دقيقة وكام ليد لكل سيلز ← شغّله.

### تشغيل على جهازك (اختياري)
```bash
npm install
cp .env.example .env.local   # واملا القيم
npm run dev                  # http://localhost:3000
```

## المميزات

- **حسابات ودخول/خروج** لكل سيلز، والأدمن بيعمل الحسابات ويوقفها.
- **صلاحيات**: أدمن / مدير مبيعات / سيلز + صلاحيات إضافية لكل يوزر (يشوف الكل، يوزّع، يستورد، يصدّر، يحذف).
- **استيراد من Excel / CSV** بربط أعمدة تلقائي (بيفهم شيتات Meta Lead Ads)، ومنع تكرار الأرقام (مصري وسعودي).
- **توزيع يدوي** بالتساوي على أي عدد سيلز.
- **توزيع تلقائي** كل فترة تحددها، بعدد ليدز لكل سيلز، في أيام وساعات الشغل بس، مع حد أقصى يومي لكل سيلز.
- **عدّاد للسيلز**: «هينزلك 5 ليدز بعد 12:30».
- **إعادة توزيع** الليدز اللي محدش كلمها بعد مدة تحددها.
- **ملاحظات + متابعات** (بعد 30 د / ساعة / ساعتين / بكرة / 3 أيام / أسبوع / ميعاد مخصص).
- **إشعارات** جوه السيستم + صوت + إشعار المتصفح لما ييجي ميعاد المتابعة أو تنزل ليدز جديدة.
- **Pipeline مخصص لإيجنسي**: جديد ← تم التواصل ← مهتم ← اجتماع ← عرض سعر ← تفاوض ← تعاقد / خسارة (مع سبب الخسارة وقيمة التعاقد).
- **أزرار اتصال وواتساب** مباشرة.
- **تصدير Excel** لليدز (بالفلاتر أو المحدد) وللتقارير.
- **تقارير**: أداء كل سيلز (نسبة التواصل، التحويل، سرعة الرد، المتابعات المتأخرة) + حسب المصدر / الخدمة / الحملة / أسباب الخسارة.
- **Webhook** لاستقبال الليدز أوتوماتيك من الموقع أو Zapier / Make.

## Webhook (ليدز أوتوماتيك من الموقع أو الإعلانات)

```
POST https://YOUR-APP.vercel.app/api/webhook/leads?key=WEBHOOK_SECRET
Content-Type: application/json

{ "name": "أحمد", "phone": "01012345678", "email": "a@b.com",
  "service": "إعلانات ممولة", "source": "Meta Ads", "campaign": "Ramadan" }
```
الليد بيدخل التوزيع التلقائي على طول. أي حقول زيادة بتتحفظ كبيانات إضافية.
